# Changelog

## Unreleased

- Added agent delivery contract and initial project-management documentation.
- Established the `Forgot the Milk` Xcode project (iPhone-only, iOS 17+, bundle `com.hoaglun.forgotthemilk`), the `Forgot the MilkTests` target, the shared scheme, and the canonical `scripts/verify.sh` build-and-test entry point.
- Delivered D1 (foundation and catalog): SwiftData schema (`HouseholdList`, `Category`, `CatalogItem`, `ListItem`, `Template`), deterministic SHA-256 seed IDs, the 26-category / 256-label seed catalog with a mechanical spec-vs-seed audit (`scripts/check_seed_catalog.sh`), idempotent first-launch seeding, complete/restore/delete/clear-completed use cases, and the list screen (category grouping, swipe actions, collapsed completed section, empty state). 24 automated tests pass through `scripts/verify.sh`.
- Delivered D2 (item workflow): the item-entry domain (`ItemDraft`, `ItemFormValidation`, `ItemEntryUseCases` add/reopen semantics, `ItemLabel`, `SettingsStore` unit-system seam), the catalog picker with search and per-item status rows, the item form (add catalog/custom, edit) with validation and metadata, save-to-catalog for custom items, category reorder in Edit mode with persisted order, and the `Forgot the MilkUITests` target with UI coverage for entry, metadata, duplicate/reopen, complete/restore, delete, search, reorder, Dynamic Type, and VoiceOver labels. `scripts/verify.sh` now runs unit and UI tests; build number bumped to 3.
- Delivered D3 (templates and email export): the template domain (`TemplateNameValidation`, `TemplateUseCases` save snapshot of needed items only, apply through `ItemEntryUseCases.add` with a changed-count report, rename, delete), the needed-only category-grouped export text (`ListExport`), and `EmailExportService` on the `MailComposing`/`ShareSheetPresenting` platform seams (mail when configured, share-sheet fallback otherwise) with DEBUG deterministic fakes; the list toolbar templates menu, save/apply/manage sheets, and the `Email list` action with accessibility labels. Adds 23 unit tests and UI coverage for template save/apply/rename/delete and the export flow; build number bumped to 4. Final end-to-end `scripts/verify.sh` run passed 2026-09-19 (build + unit + 23 UI tests green); D3 closed.
- D4 setup (2026-09-19): wired CloudKit entitlements into the app target (new `Forgot the Milk.entitlements` declaring the spec-mandated container `iCloud.com.hoaglun.forgotthemilk` and `com.apple.developer.icloud-services` = `CloudKit`, `CODE_SIGN_ENTITLEMENTS` in Debug and Release); build number bumped to 5. Simulator build green. Container provisioning in the developer account and entitlement verification in a signed build remain account-level prerequisites; no real sharing is claimed until then.
- D4 sync domain (2026-09-20): pure, unit-tested CloudKit sync core — `SyncRecord`/`SyncRecordMapping` (stable UUID identity, per-entity payloads for `HouseholdList`, `Category`, `CatalogItem`, `ListItem`, `Template`; `builtIn` items excluded from sync), `ConflictPolicy` (whole-record last-writer-wins by server modification timestamp), `MutationQueue`/`SyncBaselines` (ordered unsynced-mutation queue with a monotonic sequence; rejected mutations stay queued, never silently discarded), and `SyncState` (idle/reconciling/recoverable-error with Retry, pending and rejected counts, `ReconcileReport`). Adds four test files (record mapping, conflict policy, mutation queue, sync-state reducer). Also fixes the app launch crash introduced by the iOS 27 SDK's new `ModelConfiguration.cloudKitDatabase` default (`.automatic`): under the CloudKit entitlement the Xcode launch pipeline attempted CloudKit store integration and fatally failed store validation on non-optional model attributes; every container-creation site (app and test stores) now passes `cloudKitDatabase: .none` explicitly until the D4 reconciler and CloudKit-compatible models land. Build number bumped to 6; full Xcode test run green (158 unit + UI tests).
- D4 sync seams (2026-09-20): the `@MainActor` `CloudKitClient` protocol seam (fetch/save/delete, share lifecycle, auth status, typed `CloudKitClientError`) with a DEBUG-only `FakeCloudKitClient`/`FakeCloudKitServer` — controllable server clock stamping every write, per-device write attribution driving `shared` flags and last-writer-wins, deterministic snapshot order, one-shot injectable auth/network/permission/quota/partial-save failures, and a two-device `pair()` for contract tests (13 tests); and the `ConnectivityMonitoring` seam with `SystemConnectivityMonitor` (`NWPathMonitor`, main-actor hop) and a DEBUG-only `FakeConnectivityMonitor` with change-only notifications (4 tests). The reconciler, the real `CKContainer`-backed adapter, and the sharing use cases remain. Adds the single-size 1024×1024 app icon. Hardens the UI-test keyboard clear loop against transient AX scroll-to-visible failures, and gives the `scripts/verify.sh` UI phase a 30-minute watchdog with one retry on an erased simulator (Xcode 26 parallel-clone wedges can otherwise hang the gate indefinitely). Build number bumped to 7.
- D4 sync engine (2026-09-21): the real `CKContainer`-backed `RealCloudKitClient` adapter (auth status; cursor-paged fetch of all five entity types from the household zone — owner private zone, deterministic shared-zone discovery for collaborators, private-zone creation fallback; non-atomic per-record saves and `ifServerRecordUnchanged` deletes; `CKShare` create-or-reuse with stored-URL metadata refresh and owner stop-share; typed `CKError` → `CloudKitClientError` mapping); `SyncReconciler` (single pull/merge/push pass over stable UUIDs: last-writer-wins merge, remote adoption, remote-deletion application with superseded-local tombstones, deterministic in-order replay of pending pushes and deletes, `SyncJournal` baseline persistence); `SyncCoordinator` (`@MainActor @Observable` single-flight driver: launch/foreground/connectivity/retry triggers, `SyncState` plus share-info refresh, OSLog without PII); app wiring in `ForgotTheMilkApp` (coordinator over `container.mainContext`, scene-phase `foreground()`, DEBUG `fakeCloudKit` launch-argument seam). Adds 11 deterministic unit tests (reconciler merge/delete/partial-failure and coordinator trigger/retry/single-flight/share-refresh). The D4 suites create their context via `TestStore.makePlainContext` (plain `ModelContext`) because `container.mainContext.insert` crashes the iOS 27.0 simulator test host nondeterministically inside SwiftData (see DECISIONS 2026-09-21). Build number bumped to 8.
- D4 sharing and settings (2026-09-21): the sharing use cases on `SyncCoordinator` — `startSharing` (create-or-reuse `CKShare` with `readWrite`, persist `ListShare` metadata on the active list, present the share sheet), `stopSharing` (owner only; deletes the share, clears local metadata, keeps the local list), `acceptShareURL` (per-device `ShareInfo` with `isOwner`, shared-list adoption through the reconciler, metadata persistence including when the shared list was already adopted before acceptance) — and the settings UI (`SettingsView`: iCloud account status, sync status with plain-language error text and Retry, last-synced/pending rows, collaborators with permission levels, `Share List`/`Stop Sharing` with confirmation alert and owner-only gating, disabled sharing controls plus recovery instruction while iCloud is unavailable, unit-system picker, About/privacy statement; every new surface carries accessibility identifiers and hints). Two production fixes: the coordinator's `onShareChange` and connectivity-change callbacks now hop to the main actor instead of touching `@MainActor` state from background queues (latent data race under Swift 5 minimal checking), and `SyncReconciler` reports an `.authentication` failure when the auth status is `.unavailable` (no account / temporarily unavailable) so Settings shows a plain-language state instead of a misleading "Up to date" (spec §4.4). New `fakeCloudKitUnavailable` DEBUG launch-argument seam. Adds 8 deterministic unit tests (share create/reuse/stop/accept flows, adopt-then-accept metadata persistence, active-list persistence across restart, per-device `acceptShareURL` share info, unavailable-account reconcile failure) and 4 UI tests (unshared state, full share/stop-share round trip through the system share sheet, unavailable-state disabled sharing with recovery hint, accessibility-size settings surface). Build number bumped to 9. The container `iCloud.com.hoaglun.forgotthemilk` is reported provisioned (Xcode account shows one enabled container, 2026-09-21); signed-build entitlement verification and the manual two-Apple-ID smoke remain open.
